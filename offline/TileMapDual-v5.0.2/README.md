# Offline TileMapDual v5.0.2

This folder is an offline copy of the `addons/TileMapDual` plugin from:

```text
https://github.com/pablogila/TileMapDual
```

Tested source version: `v5.0.2`.

To install, copy `addons/TileMapDual` into the target Godot project's `addons/` folder, then enable it in `Project > Project Settings > Plugins`.

The plugin is MIT licensed. Keep `LICENSE` with redistributed copies.
