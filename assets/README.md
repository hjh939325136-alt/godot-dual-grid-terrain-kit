# Windmill Reference Asset

`windmill-reference-guide.png` is the fixed Dual Grid windmill reference.

- Canvas: `1024x1024`.
- Logical grid: `4x4`, each cell `256x256`.
- The purple lines are an inspection overlay only.
- The green shape represents one continuous terrain silhouette.
- Do not use the guide-line version as the final image-generation input or compiler source.

For generation, create a clean copy without the purple grid, keep the same stepped silhouette, and request a full-size RGBA PNG.
